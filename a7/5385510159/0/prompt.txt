**1. How Markdown headings become symbols**

- Each heading becomes kind `section` with Name = `slugName(heading text)` and Signature = `"markdown heading &lt;text&gt;"`. **StartLine and EndLine are both the heading line.** The section has no body range.
- Code fences become `code_fence_&lt;n&gt;_&lt;lang&gt;` symbols, also one line each.
- **Bug:** the scanner never tracks whether it is inside a fence. A `# comment` line inside a bash fence becomes a section.
- Entities turn into symbols in `entitySymbols` (`provider.go:1976`). The ID is `symbolID(repo, "Markdown", path, "section", name)` (`provider.go:28462`). Duplicate headings get a `#sig:&lt;hash&gt;` suffix, then `#2`, `#3` for identical text (`2020-2032`).
